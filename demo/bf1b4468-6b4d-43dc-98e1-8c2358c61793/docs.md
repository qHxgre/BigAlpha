# 订单簿压力因子（Order Book Pressure Factor, OBPF）说明文档

## 1. 因子概述

### 1.1 因子定义

**订单簿压力因子 (OBPF)**是一个基于L2订单簿快照数据计算的高频技术指标，用于量化股票市场的买卖压力平衡状态。该因子通过分析订单簿的多个维度（不平衡度、价差、深度），在15分钟时间窗口内综合反映市场微观结构的变化。

### 1.2 核心思想
OBPF的核心思想是：订单簿的结构变化领先于价格变化。通过实时监测订单簿的买卖力量对比、流动性和支撑阻力状况，可以提前捕捉价格变动的信号。

## 2. 金融逻辑解释

### 2.1 市场微观结构理论基础

#### 2.1.1 信息不对称理论
- **逻辑**：知情交易者通过订单簿传递私有信息
- **OBPF体现**：大额订单集中在一侧时，因子值会显著偏离平衡状态

#### 2.1.2 流动性提供者行为
- **逻辑**：做市商和机构投资者根据订单簿调整报价
- **OBPF体现**：价差扩大时因子敏感性降低，反映流动性枯竭

#### 2.1.3 订单流不平衡理论
- **逻辑**：买卖订单流的持续不平衡最终导致价格变动
- **OBPF体现**：加权不平衡度作为核心输入，直接衡量订单流压力

### 2.2 因子各组成部分的金融含义

#### 2.2.1 加权订单簿不平衡度（Weighted Order Book Imbalance）

$$
\text{Imbalance} = \frac{\sum_{i=1}^{5} e^{-0.3(i-1)} \cdot \text{BidVolume}_i - \sum_{i=1}^{5} e^{-0.3(i-1)} \cdot \text{AskVolume}_i}{\text{Total Weighted Volume}}
$$

**金融解释**：
1. **指数衰减权重**：越靠近最佳报价的档位对价格影响越大
   - 买一/卖一档的权重最高（权重≈1.0）
   - 第五档的权重约为0.74（e^{-0.3×4}）
2. **方向性信号**：
   - 正值：买盘力量强于卖盘，预期价格上涨
   - 负值：卖盘力量强于买盘，预期价格下跌
3. **实际意义**：
   - 反映机构投资者的建仓/平仓行为
   - 捕捉大宗交易的信号泄露

#### 2.2.2 相对价差因子（Relative Spread）

$$
\text{RelativeSpread} = \frac{\text{AskPrice}_1 - \text{BidPrice}_1}{\text{MidPrice}}
$$

**金融解释**：
1. **流动性指标**：
   - 价差越小，市场流动性越好，交易成本越低
   - 价差扩大通常伴随不确定性增加或流动性减少
2. **风险感知**：
   - 高波动预期导致做市商扩大报价价差
   - 极端事件前的预警信号
3. **对压力因子的调整作用**：
   - 价差扩大时，同样的不平衡度意义不同（分母√(spread)）
   - 避免在流动性差时过度解读订单簿信号

#### 2.2.3 深度比率（Depth Ratio）

$$
\text{DepthRatio} = \frac{\text{BidDepth}_{1-3} - \text{AskDepth}_{1-3}}{\text{TotalDepth}_{1-3}}
$$

**金融解释**：
1. **支撑/阻力强度**：
   - 正值：买盘支撑强于卖盘阻力
   - 负值：卖盘阻力强于买盘支撑
2. **价格弹性**：
   - 深度比率影响价格变动的难易程度
   - 深度大的一侧更难被突破
3. **实际交易意义**：
   - 大单执行成本估计
   - 突破关键价位的可能性评估

#### 2.2.4 原始压力因子合成

$$
\text{RawPressure} = \frac{\text{Imbalance}}{\sqrt{\text{RelativeSpread}}} \times \text{DepthRatio}
$$

**合成逻辑**：
1. **分子部分**（不平衡度调整）：
   - 不平衡度除以价差平方根：流动性越好，同样不平衡度的信号越强
   - 避免在价差过大时过度解读不平衡信号
2. **乘以深度比率**：
   - 深度支持的方向与不平衡方向一致时，信号增强
   - 深度与不平衡方向相反时，信号减弱（可能发生反转）
3. **金融直觉**：
   - 买方压力 = 买盘不平衡 × 买盘深度优势 ÷ 流动性调整
   - 卖方压力 = 卖盘不平衡 × 卖盘深度优势 ÷ 流动性调整

## 3. 15分钟窗口处理逻辑

### 3.1 时间窗口选择依据

#### 3.1.1 交易行为时间尺度
- **超短期（<5分钟）**：噪声主导，信号不稳定
- **短期（5-15分钟）**：机构算法交易的主要时间尺度
- **中期（15-30分钟）**：基本面信息开始反映
- **长期（>30分钟）**：宏观因素主导

**选择15分钟的理由**：
1. 足够捕捉订单簿的持续性变化
2. 过滤掉高频噪声和临时性冲击
3. 与常见的技术分析周期（15分钟K线）对齐

### 3.2 窗口内标准化处理

```python
# 标准化公式
standardized_pressure = (current_raw_pressure - window_mean) / window_std
```

**金融意义**：
1. **去除趋势影响**：
   - 减去均值：消除窗口内的系统性偏移
   - 使因子反映相对变化而非绝对水平
2. **波动率调整**：
   - 除以标准差：不同波动率环境下因子可比
   - 高波动时信号需要更强才有意义
3. **Z-score转换**：
   - 转换为标准正态分布
   - 便于设定统一的交易阈值

### 3.3 波动率调整机制

```python
# 高波动率调整
if volatility > volatility_threshold:
    adjusted_pressure = standardized_pressure * 0.7
```

**调整逻辑**：
1. **波动率阈值**：历史波动率的80%分位数
2. **调整系数**：0.7（高波动时降低因子敏感性30%）
3. **金融原理**：
   - 高波动时订单簿噪声增加
   - 单一订单簿信号的预测能力下降
   - 需要更保守的信号解读

### 3.4 非线性变换（tanh函数）

```python
final_factor = np.tanh(adjusted_pressure)
```

**变换特性**：
1. **值域限制**：将因子限制在[-1, 1]区间
   - -1 ≤ OBPF ≤ 1
   - 避免极端值影响
2. **边际递减**：
   - 输入值越大，输出增加越慢
   - 符合风险厌恶心理
3. **对称性**：
   - tanh(-x) = -tanh(x)
   - 买卖压力对称处理

### 3.5 记忆效应（指数平滑）

```python
# 指数加权移动平均
factor_smoothed = factor_value.ewm(alpha=0.3, adjust=False).mean()
```

**平滑逻辑**：
1. **α=0.3**：当前值权重30%，历史值权重70%
2. **金融意义**：
   - 市场压力具有持续性
   - 避免因子频繁反转
   - 平滑噪声，突出主要趋势
3. **时间衰减**：
   - 越近的数据权重越大
   - 符合信息衰减规律

## 4. 因子特性分析

### 4.1 统计特性
| 特性 | 数值范围 | 理想分布 | 实际意义 |
|------|---------|----------|----------|
| **值域** | [-1, 1] | 集中在[-0.5, 0.5] | 避免过度交易 |
| **均值** | ≈0 | 略微偏正（A股特性） | 反映市场长期向上倾向 |
| **标准差** | 0.2-0.4 | 适中 | 提供足够的交易信号 |
| **偏度** | 略为负偏 | 对称最好 | 下跌压力可能更剧烈 |
| **自相关性** | 0.3-0.6（滞后1） | 中等正相关 | 压力具有持续性 |

### 4.2 市场状态适应性

#### 4.2.1 趋势市场
- **因子表现**：持续性较好
- **信号质量**：高
- **调整机制**：深度比率增强趋势确认

#### 4.2.2 震荡市场
- **因子表现**：均值回复性强
- **信号质量**：中等
- **调整机制**：价差调整防止假突破

#### 4.2.3 高波动市场
- **因子表现**：噪声增加
- **信号质量**：降低
- **调整机制**：波动率下调权重

## 5. 交易信号解读

### 5.1 信号强度分类

| OBPF值域 | 信号强度 | 交易含义 | 建议仓位 |
|---------|---------|----------|----------|
| **<-0.7** | 极强卖压 | 强烈看空 | 可考虑做空 |
| **-0.7 ~ -0.3** | 较强卖压 | 看空 | 减仓或观望 |
| **-0.3 ~ 0.3** | 平衡状态 | 中性 | 持仓观察 |
| **0.3 ~ 0.7** | 较强买压 | 看多 | 加仓或建仓 |
| **>0.7** | 极强买压 | 强烈看多 | 可考虑加杠杆 |

### 5.2 信号确认机制

#### 5.2.1 单信号确认
- **阈值突破**：连续2-3期超过阈值
- **趋势确认**：因子方向与价格趋势一致
- **量价配合**：成交量放大时信号更强

#### 5.2.2 多信号组合
1. **OBPF与价格背离**：
   - 价格上涨 + OBPF下降 → 潜在顶部
   - 价格下跌 + OBPF上升 → 潜在底部

2. **OBPF与成交量**：
   - 高OBPF + 放量 → 突破信号强
   - 高OBPF + 缩量 → 可能假突破

### 5.3 实战应用场景

#### 5.3.1 日内交易
- **时间框架**：15分钟K线
- **进场信号**：OBPF突破±0.5且持续
- **出场信号**：OBPF回归零轴或反向突破
- **止损设置**：根据因子反转信号

#### 5.3.2 算法交易增强
- **执行算法**：OBPF指导VWAP/TWAP参数
- **时机选择**：高买压时激进买入，高卖压时推迟卖出
- **订单类型**：压力强时用市价单，平衡时用限价单

#### 5.3.3 风险控制
- **黑天鹅事件**：OBPF极端值预警
- **流动性风险**：价差因子监控
- **模型风险**：定期回测和参数更新

# GIFP 2026 单因子评估

输入必须且只能包含 `date`、`instrument`、`factor` 三列。评估器将提交结果
对齐 `cpt_gifp_2026_instruments` 的沪深 300 历史成分股 15 分钟面板；每个
截面的缺失率不得高于 40%。

预处理流程与进益资本评估模块保持一致：截面 3 倍标准差去极值、截面
z-score 标准化，再使用 `cpt_gifp_2026_exposure` 中的 BARRA 风格因子和
行业哑变量做截面回归，使用残差因子参与评估。

收益标签来自 `cpt_gifp_2026_return.return_rate`，表示从当前 15 分钟采样
时点到下一交易日同一分钟的复权收盘价收益。评估时以同截面股票池的等权
平均收益作为基准，计算个股超额收益。

返回五项原始指标：

- `ic_mean`：各 15 分钟截面 Spearman RankIC 的均值。
- `ic_ir`：截面 RankIC 均值除以其样本标准差。
- `sharpe_ratio`：十分组最高组减最低组收益的年化夏普，按
  `16 × 242` 个周期年化。
- `turnover`：相邻日内截面最高组、最低组单边换手率的平均值；隔夜不计。
- `max_drawdown`：多空组合复利净值的最大回撤幅度，返回非负数。

比赛总分中的百分位排名需要在全体有效提交之间计算，不属于单次评估函数
可独立生成的结果；其中换手率和最大回撤均为越低越好。

# 建模说明：C6 五档全量冠军固定 ep26

对应 AIStudio 目录：

    /home/aiuser/work/BigAlpha/c2c_c6_20260729/c2c_champion_5level_full_2024_ep26

这是已经成功完成全量训练的 C6 champion 包。它在平台五档原始字段上训练一个单 seed、单 checkpoint 的 PatchTST 日终横截面预测模型，当前固定使用 epoch 26 的状态。

## 1. 输入合同

数据源是 bigalpha_2026_stock_bar1m，模型消费赛方提供的 37 个五档原始字段：

- 14 个价格字段：open、high、low、close、ask_price1–5、bid_price1–5。
- 23 个非价格字段：deal_number、volume、amount、ask_volume1–5、bid_volume1–5、ask_num_orders1–5、bid_num_orders1–5。

date 和 instrument 只用于构造时间窗口、日期截面和结果索引；adjust_factor 用于价格标准复权，不是模型通道。没有加入 return、spread、imbalance、ratio、delta、OHLC 聚合、技术指标或其他固定派生输入。下文的收益公式只定义监督标签，不是输入特征工程。

## 2. 样本和标签

每个标的在交易日 t 形成一个 120×37 的样本窗口：取连续 120 根 bar1m，窗口末端是 t 的最后一根已完成 bar。训练覆盖 2019-07-01 至 2024-12-31 23:59:59，checkpoint 记录 2,431,873 个训练样本和 1,989 个标的。

令 C_t 为复权收盘价，O_(t+1)、C_(t+1) 为下一交易日的复权开盘价和收盘价。监督目标为：

- 主标签 shrink05：y_main = log(O_(t+1) / C_t) + 0.5 × log(C_(t+1) / O_(t+1))。
- 辅助标签 overnight：y_aux = log(O_(t+1) / C_t)。
- 同时保留 close-to-close 标签；当开盘或组件无效时，代码使用有限的 close-to-close 对数回退值。

主、辅助标签都按日期做横截面 z-score，并裁剪到 [-3, 3]。训练损失是同日横截面的相关性损失：主分支拟合 shrink05，辅助分支拟合 overnight，辅助项的权重是 0.2。辅助标签的无效组件不进入辅助损失。

## 3. 输入预处理：logrel + 全量训练统计量

### 3.1 canonical 清洗

- 14 个价格字段乘 adjust_factor，并在标的内按时间 forward-fill。
- 23 个非价格字段缺失填 0、截断到非负，再计算 log1p(max(x, 0))。

### 3.2 价格 logrel

令 T 是样本最后一根已完成 bar，C_T 是该 bar 的 close。14 个价格字段都使用同一个末端 close 作为价格锚点：

    z_(i,τ,f) = log(max(x_(i,τ,f), 1e-6)) - log(max(C_T, 1e-6))

非价格字段保持 log1p 后的 level。该 logrel 轴只是在原始字段上做基础归一化，没有产生新的字段；使用的末端 close 是日终预测信息边界内已完成的原始 bar。

### 3.3 训练期 mean/std

在完整训练窗口构造窗口后，沿所有训练样本、时间位置和字段计算每个字段的 mean/std；std 加 1e-6 防止除零。训练输入减去该 mean，再除以该 std；缺失和非有限值最终置为 0。推理时只读取 checkpoint 中保存的同一组 mean/std，不在推理窗口重新拟合。

checkpoint 中 input_preprocess 的 post_standardize 为 identity，含义是 logrel 和训练统计量已经完成后不再追加 C6 clamp；它不表示完全不做输入归一化。

本包不使用 field-last CS-MAD，也不对每个推理日重新拟合横截面 median/MAD。与 augmentation ep13 的差异是：C6 使用共同 close 锚点和全量训练静态统计，ep13 使用每个价格字段自己的末端锚点和运行时完整日截面 CS-MAD。

## 4. 网络结构

C6 与 augmentation ep13 的主干和 head 相同：

1. 输入形状为 [N,120,37]。
2. patch_len=16、stride=8，得到 14 个 patch；每个 patch 的 592 维展平向量线性投影到 128 维。
3. 加可学习位置参数，经过 3 层 TransformerEncoder；每层 4 个 head、前馈层宽度 256、GELU、norm_first=True、dropout=0.1。
4. learned attention pooling 汇聚 14 个 hidden patch，得到 128 维样本表示。
5. 主 head：LayerNorm → Linear(128,256) → GELU → Dropout(0.1) → Linear(256,1)。
6. 辅助 head：LayerNorm → Linear(128,128) → GELU → Dropout(0.1) → Linear(128,1)。

训练返回 main 和 aux 两个输出；推理只使用 main。没有跨标的 attention，也没有额外的输出 ensemble。

## 5. 训练策略

package_config 固定为 variant=shrink05_aux、aux_weight=0.2、seed=42、top_k=1、fixed_epochs=[26]。优化器为 Adam，初始学习率 5e-4；每个训练步骤采用 8% warmup 后 cosine decay，梯度范数裁剪为 1.0。当前包未启用 feature zero 或 investment mask，训练输入保持预处理后的完整样本。

这是生产式全量训练合同：

- full_train_no_test=true；不构造测试集，不使用测试曲线选 epoch，不记录验证样本指标。
- 完整执行 30 个 epoch，在训练过程中缓存预注册的 epoch 26 状态，训练完成后写出唯一 checkpoint。
- checkpoint：model_s42_k1.json，seed=42、rank=1、epoch=26。
- 训练入口为 platform_train.py；它负责调用本目录 transformer_train.py 的训练逻辑并生成该唯一权重。

epoch=26 是预注册固定点，不是由本次 full-train 的测试集或 2024 诊断曲线选出的。加载时应检查模型结构、37 字段顺序、logrel 及 mean/std 语义、seed、rank、epoch 和 package_config 等实际合同；源码路径或 SHA 不属于运行时 checkpoint 放行条件。

## 6. 推理和评测输出

Notebook 当前示例用 2024-01-01 00:00:00 至 2024-12-31 23:59:59 生成完整年度 score 并调用平台评测函数；正式比赛的推理窗口由平台决定，调整日期不会改变模型权重。

predict_ensemble 的输出处理如下：

1. 按 5 天日期块读取数据，查询批次最多 100 个标的；模型前向 batch 默认 1024。
2. 对唯一模型的 main 输出按日期做横截面 z-score。
3. 对模型 z-score 做均值；因为 seed42、rank1 只有一个模型，这一步不产生实际融合。
4. 每日按平均分排序，使用 norm.ppf((rank-0.5)/n) 生成 rank-gauss 分数。
5. 只输出 date、instrument、score，合并平台标的表后去重并清除非有限值。

5 天日期块、100 标的查询批次是 C6 成功包的内存安全运行包络；它们只影响分块读取和中间对象峰值，不改变完整日截面 z-score、rank-gauss 或最终排序语义。

## 8. 方案摘要

C6 的建模取舍是保持 37 个原始五档字段不变，用共同末端 close 的 logrel 把价格通道放到相对尺度，再由全量训练统计量完成固定标准化；模型使用共享 PatchTST 编码器和 shrink05/overnight 双头，以主 head 作为单模型日终分数。它没有训练期输入 dropout、截面子采样或多模型融合，最终以固定 seed42、epoch26 的单 checkpoint 运行。

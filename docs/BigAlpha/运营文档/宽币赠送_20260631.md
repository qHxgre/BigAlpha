## 二、社媒分享任务说明

在小红书、朋友圈或参赛社群分享 BigAlpha 2026 相关内容，提交凭证后可获得算力奖励，**每人最多 3 次**。

**如何申请**

填写官方腾讯问卷，提交以下信息：
- 比赛报名 ID
- 帖子链接（小红书）或发布截图（朋友圈 / 社群）
- 发布时间

**发放说明**

- 每周统一审核上一周提交的申请，审核通过后发放算力
- 通过标准：帖子真实有效、含赛事相关内容、报名 ID 匹配
- 同一帖子不可重复提交；未通过的申请不补发，但计入申请次数

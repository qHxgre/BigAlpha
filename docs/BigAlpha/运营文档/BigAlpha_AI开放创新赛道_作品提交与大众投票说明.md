# BigAlpha AI 开放创新赛道
## 作品提交与大众投票说明

通过组委会初审的项目将在赛事页面“作品广场”公开展示，并参与专家评审和大众投票。

## 一、重要时间

- **作品提交时间：7月27日—8月2日**
- **大众投票时间：8月2日—8月12日**

最终安排以赛事页面及组委会最新通知为准。

## 二、初赛成绩

> **初赛最终成绩 = 专家评分 × 50% + 大众热度分 × 50%**

专家评分维度：

- AI应用创新性：35分
- 方案完整性：35分
- 应用前景与产业落地价值：20分
- 项目表达与展示质量：10分

大众热度分根据异常票清洗后的有效票数排名，在60—100分之间折算。大众投票不作为单一晋级或评奖依据。

## 三、作品提交内容

### 1. 公开展示资料

| 内容 | 必填 | 要求 |
|---|---|---|
| 项目名称 | 是 | 30字以内 |
| 项目封面 | 是 | 16:9，JPG/PNG，不超过3MB |
| 一句话摘要 | 是 | 60字以内 |
| 项目公开介绍 | 是 | 500字以内 |
| 核心创新点 | 是 | 最多3条 |
| 团队展示名称 | 否 | 30字以内 |
| 公开展示授权 | 是 | 确认可在作品广场展示 |

### 2. 作品详情材料

**Demo、文档或代码为必填材料，仅供主办方和评审人员审阅，不对外展示。**

请至少提供一种能够证明项目真实完成度的材料，并确保链接、测试账号、密码或运行说明在评审期间有效。

## 四、公开展示与修改

作品广场将展示：

- 项目名称
- 项目封面
- 学校及团队名称
- 一句话摘要
- 项目公开介绍
- 核心创新点
- 当前热度
- 投票入口

Demo地址、代码、内部文档及其他仅供评审使用的材料不会对外公开。

作品正式发布后，项目名称、封面、摘要及核心内容原则上不可自行修改；确需修改时，请联系组委会。

## 五、大众投票规则

- 每个登录账号拥有6张支持票。
- 同一账号对同一项目最多投3票，可将票数分配给多个项目。
- 投票提交后原则上不可撤回或修改。
- 只有通过组委会初审并进入作品广场的项目可以参与投票。
- 投票期间原则上不实时公开原始票数，仅展示阶段性热度。

## 六、异常投票与违规处理

投票结束后，组委会将核验投票数据。

批量注册、脚本投票、买票、刷票、异常集中投票等行为，将视情况：

- 剔除异常票；
- 调整大众热度分；
- 取消参评、晋级或获奖资格。

参赛作品不得存在抄袭、虚假成果、知识产权侵权、未经授权公开他人数据或代码、误导性金融建议等情况。

## 七、提交前检查

- [ ] 公开展示资料填写完整，封面和文字适合对外发布。
- [ ] Demo、文档或代码已提交，且可正常访问或运行。
- [ ] 测试账号、密码或特殊操作方式已附清晰说明。
- [ ] 使用的开源模型、代码、数据集或第三方工具已作必要说明。

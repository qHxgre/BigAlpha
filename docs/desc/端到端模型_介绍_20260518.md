# BigAlpha 端到端量化模型竞赛 · 技术规范

> 版本：v1.2  
> 更新日期：2026-05-19

本文档仅描述端到端模型比赛的技术规范，不含赛程、奖项、报名等管理性内容。

---

## 一、任务定义

参赛者构建**单一深度模型**，以主办方提供的原始行情、财务、资金流等数据为输入，**直接输出**每个交易日的中证 1000 截面持仓权重，使日频持仓在样本外回测中获得稳定的风险调整后超额收益。

**考察重点**

* 多频率、多模态原始数据的端到端建模能力。
* 风险与换手成本的内生控制能力。

**不考察**

* 手工因子构造。
* 独立的组合优化求解。

---

## 二、数据

### 2.1 股票池

中证 1000 指数在历史相应时间点上的成分股，按月动态调整。每日的可投资域为**当日**成分股。

### 2.2 数据内容

所有数据均已做 PIT（Point-in-Time）处理，避免未来函数。

| 数据类别 | 说明 |
|---|---|
| K 线及盘口快照 | 1 分钟 / 10 分钟 / 30 分钟 / 日频多频率 |
| 财务数据 | PIT 处理并对齐为日频，含常见财务字段与财务指标 |
| 基本信息 | 股票状态（停牌、ST、退市风险）、两融标的、股本结构等 |
| 加工数据 | 资金流、估值指标（PE / PB / PS / EV 等） |

### 2.3 时间切分

| 区间 | 用途 | 数据可见性 |
|---|---|---|
| 2020-01-01 ~ 2022-12-31 | 训练集 | 参赛者可见 |
| 2023-01-01 ~ 2023-12-31 | 验证集 | 参赛者可见 |
| 2024-01-01 ~ 2024-06-30 | 公开榜（样本外） | 参赛者可见 |
| 2024-07-01 ~ 2024-12-31 | 隐藏榜（样本外） | 主办方扣留，赛后用于最终评测 |

数据隔离由主办方在分发层面实现：参赛者物理上无法获取 2024-07-01 之后的数据。

## 三、模型规范

### 3.1 输入约束

1. **特征上限**：模型输入字段不超过 **50 个原始字段**。时序窗口的同一字段在不同时间步上仍计为 1 个字段（即时序长度不计入字段数）。
2. **数据来源**：所有输入字段必须直接来源于主办方提供的数据。**禁止任何衍生或人工特征工程**，包括跨字段算子、滚动统计、因子合成、降维、第三方数据等。
3. **允许的预处理**：缺失值填充、按字段统一的归一化（MinMax / StandardScaler）、按字段统一的对数或符号变换。预处理参数仅基于训练集统计得到。
4. **时序窗口上限**：单次推理回看窗口 ≤ **240 个交易日**。

### 3.2 输出约束

模型须输出每个交易日的截面持仓权重 $w_{t,i}$，满足：

* $w_{t,i} \ge 0$（不允许做空）；
* $\sum_i w_{t,i} = 1$（容差 1e-6）；
* 单只股票权重 ≤ **5%**；
* 当日不在中证 1000 成分股内的股票权重视为 0；
* 当日停牌、一字涨跌停、退市的股票权重视为 0；
* 上述置零后剩余权重按比例重新归一化。

### 3.3 模型约束

1. **可训练参数量**：≥ 100,000（10 万），≤ 100,000,000（1 亿）。
2. **外部预训练权重**：禁止使用任何外部预训练权重。所有参数由参赛者基于本竞赛数据从零训练。
3. **架构形态**：未做硬性指定，但参数量下限与禁特征工程的组合，意味着浅层模型（XGBoost、线性模型）难以达到有竞争力的成绩。

### 3.4 训练目标

**主办方不指定训练目标（loss）**。参赛者可自由设计标签、损失函数与训练策略——这是端到端建模的核心设计空间，与模型架构同等重要。

无论使用哪种训练目标，最终都按 *五、评分* 中的指标在样本外排名，谁的训练目标更接近真实评测，谁的最终成绩越好。

为方便上手，下表给出三条参考路径，**仅作非强制性指引**：

| 路径 | 训练目标 | 推理后处理 | 难度 | 特点 |
|---|---|---|---|---|
| A · 回归 | 预测 $T+1 \sim T+N$ 收益的 MSE / IC loss | softmax + top-K 截断 + 归一化 | 低 | 与传统监督学习一致，单 GPU 几小时即可出基线 |
| B · 截面排序 | ListMLE / ListNet / pairwise ranking | 同 A | 中 | 直接对齐"哪只股票相对更好"，IC 通常优于 A |
| C · 可微回测 | 负的组合 IR / Sharpe / 扣费净收益 | 模型直接输出权重 | 高 | 训练目标与评测指标完全一致，上限最高，但训练动力学难调 |

**路径 C 最贴近"端到端"的理念**。一个最小可行的可微 IR loss 示意：

```python
# 一个 batch = 一段时间窗口
weights = model(features)                                # [T, N]
ret_port = (weights * future_1d_returns).sum(dim=-1)     # [T]
ret_excess = ret_port - benchmark_returns                # [T]
loss = -ret_excess.mean() / (ret_excess.std() + 1e-8)    # 负 IR
loss = loss + lam * (weights[1:] - weights[:-1]).abs().sum()  # 换手惩罚
```

参赛者也可使用上述路径之外的任意训练目标（强化学习、对比学习、多任务等），主办方不审计训练过程，仅以样本外表现评判。

## 四、提交内容

### 4.1 提交材料

| 材料 | 说明 |
|---|---|
| 持仓文件 | 覆盖公开榜区间（2024-01-01 ~ 2024-06-30）的完整持仓 CSV，含 `date / instrument / weight` 三列 |
| 模型代码 | 含训练、推理的完整脚本 |
| 模型权重 | 训练得到的权重文件 |
| 推理脚本说明 | README，说明如何用提交的代码+权重对任意区间生成持仓文件 |
| 依赖清单 | `requirements.txt`，列出 Python 依赖与版本 |

公开榜阶段，参赛者只需提交持仓文件即可获得分数反馈；最终冻结时一并提交以上全部材料。

### 4.2 持仓文件校验

提交持仓文件须通过以下机器校验，任一项不通过视为提交不计入评分：

* **格式**：仅含 `date / instrument / weight` 三列。
* **权重**：每个交易日权重之和为 1（容差 1e-6），权重 ≥ 0，单票 ≤ 5%。
* **完整性**：评测区间内每个交易日都有持仓。
* **可投资域**：所持有的股票必须在当日中证 1000 成分股内。

## 五、回测与评分

### 5.1 回测设定

| 项目 | 设定 |
|---|---|
| 撮合价 | T+1 次日开盘价 |
| 双边交易成本 | 千分之三（含佣金、印花税、滑点的综合成本） |
| 基准 | 中证 1000 全收益指数 |
| 调仓频率 | 日频 |

调仓日不可买卖的股票按 *3.2 输出约束* 处理。

### 5.2 准入门槛

满足以下全部条件方进入正式排名：

1. *3.1 ~ 3.3* 模型约束全部通过（机器自动校验）。
2. *4.2* 持仓文件校验全部通过。
3. 公开榜区间内年化超额收益 ≥ 0。

### 5.3 评分公式

$$
Score = 0.4 \cdot R_{IR} + 0.3 \cdot R_{ExRet} + 0.3 \cdot R_{NetRet}
$$

* $R_X$：指标 $X$ 在所有进入正式排名的提交中的百分位（归一化到 [0, 1]，越大越好）。
* 公开榜与隐藏榜分别按上述公式计算，**最终排名以隐藏榜得分为准**。

### 5.4 指标定义

| 指标 | 定义 |
|---|---|
| $IR$ | 信息比率：日度超额收益均值 × 252 ÷（日度超额收益标准差 × √252） |
| $ExRet$ | 相对中证 1000 全收益指数的年化超额收益（不扣费） |
| $NetRet$ | 扣除 *5.1* 中交易成本后的年化超额净收益 |

所有指标基于样本外区间计算。

## 六、评测执行

### 6.1 隐藏榜执行流程

主办方对所有进入准入门槛的提交执行以下流程：

1. 加载参赛者的代码、权重与依赖清单。
2. 在 2024-07-01 ~ 2024-12-31 区间运行推理脚本，产出持仓文件。
3. 对该持仓文件运行 *4.2* 的机器校验。
4. 校验通过则进入回测，按 *5.3* 计分。

参赛者须确保提交的代码+权重在主办方机器上能运行通过。**因代码错误、依赖缺失、运行超时导致主办方无法生成持仓的，视为放弃隐藏榜评测，不计入最终排名。**

### 6.2 推理时长上限

每份提交在主办方机器上完成 6 个月（约 120 个交易日）推理的总时长 ≤ *附录 B 中 T_max*。超时视为提交无效。

### 6.3 公开榜一致性校验

主办方对**最终隐藏榜 Top-N**（N 见附录 B）执行一致性校验：

* 用参赛者提交的代码+权重在 2024-01-01 ~ 2024-06-30 区间重新生成持仓。
* 与参赛者提交的公开榜持仓文件逐日逐股对比，权重绝对差异平均值 ≤ **1%** 视为一致。
* 不一致的提交视为公开榜成绩造假，取消资格。

本流程**仅复现推理，不要求重新训练**。

### 6.4 数据使用合规

* 严禁使用任何外部数据，包括另类舆情、研报、外部行情源、未来公告、外部预训练权重。
* 严禁通过提交的代码、权重或数据夹带未来信息。

| 术语 | 含义 |
|---|---|
| PIT (Point-in-Time) | 仅使用截至某时刻已可获得的信息，避免未来函数 |
| 端到端模型 | 单一模型直接从原始输入产出最终决策，无独立的特征工程或组合优化阶段 |
| 公开榜 | 参赛期间可见、参赛者可针对其提交并获得分数反馈的榜单 |
| 隐藏榜 | 仅由主办方在赛后揭晓的榜单，决定最终排名 |

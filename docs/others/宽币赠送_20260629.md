## 运营执行说明

三个赛道的宽币数字差距，本质是**算力单价差距**，不是奖励差距：端到端用 A100（1740 宽币/小时），AI 因子用 8C/32G（192 宽币/小时），单价相差约 9 倍，所以同样"做 3 小时任务"，端到端的宽币数字必然大约 9 倍，但换算成**实际可用算力时长是一样的**。因此对外统一讲"算力时长"、不讲宽币绝对值——所有任务奖励对学生表述为"完成 X 任务 = 获得 Y 小时本赛道算力"，三个赛道在感知上对齐，避免学生因数字差距盲目涌入端到端赛道。

为防止学生为薅大额宽币而盲目报名端到端，端到端不再一次性发放大额初始礼包，改为"小额初始 + 按周滚动"的发放模式：

| 赛道 | 初始大礼包 | 后续发放方式 |
|------|------------|--------------|
| 端到端 | 5,220 宽币（约 3 小时，够跑通环境+首次提交） | 每周对"超基准分 + 周榜前 50%"的名单，每人发 10,000 宽币（约 5.7 小时） |
| AI 因子挖掘 | 5,000 宽币（报名即领，额度小无套利动机） | 按任务标准发放 |
| 开放创新 | 2,000 宽币（报名即领，额度小无套利动机） | 按任务标准发放 |

端到端把初始额度压到 3 小时、且后续按周滚动发放，发放条件设为"超过官方 baseline/模版分 + 周榜前 50%"——只跑模版或简单改改的参赛者分数过不了基准线，躺平刷分者也进不了周榜前列，从而把宽币真正给到持续优化的人。后续任务奖励（周榜、决赛等）本身也以成绩/行为为前提，天然带门槛。

对于开放式培训，保持开放、不设观看门槛，通过一个轻量参与凭证回收发放名单：

1. **培训中埋当场口令**：在每场直播/录播/文档的中段或结尾，给出一个**本场专属口令**（如一个关键词、一道题的答案、PPT 某页的代号）。口令每场不同，证明学生"真的看了本场内容"。
2. **培训后挂登记表单**：表单收集【比赛报名 ID / 手机号】+【本场口令】。
3. **后台核对发放**：口令正确 + 报名 ID 真实存在 → 发放对应宽币。
4. **防刷量补充（按需）**：若某场培训宽币额度较大、担心口令外传刷量，叠加一道**与本场内容强相关的题目**作为答题校验，人工或半自动审核后发放。

该机制不依赖平台改造、不破坏培训开放性，同时能拿到发放所需的报名 ID。

## 二、运营执行说明

### 2.1 对外口径：统一讲时长，不讲宽币

三个赛道完成同一任务，获得**相同的算力时长**，宽币数字因各赛道算力单价不同而有差异，对外不披露宽币绝对值。

| 任务  | 对外统一说法 |
|-----|--------|
| 初始礼包 | 报名即获 XX 小时算力（各赛道按规格不同） |
| 首次提交 | 完成首次提交，获得 3 小时额外算力 |
| 提交里程碑 | 每达到提交里程碑，获得 3–5 小时算力 |
| 周榜前 30% | 每周进入周榜前 30%，获得额外算力支持 |
| 社媒发帖 | 发布内容并提交凭证，获得 3 小时算力，每人最多 3 次 |
| 进入决赛 | 晋级决赛，获得额外算力奖励 |

### 2.2 社媒任务：批量限额审核流程

**申请方式：** 参赛者填写腾讯问卷，提交以下信息：

* 比赛报名 ID
* 帖子链接（小红书 / 朋友圈截图 / 社群发言截图）
* 发布时间

**审核规则：**

* 每周一批量处理上一周申请，预估每赛道 30 分钟内完成
* 每赛道每周审核上限 50 条，超出顺延至下周，不积压
* 通过标准：帖子真实存在、含赛事相关内容、报名 ID 匹配

**防刷规则：**

* 每人累计最多申请 3 次
* 同一帖子不可重复提交
* 审核不通过的申请计入次数，不补发

### 2.3 端到端防套利机制

初始礼包压至 3 小时，后续以「超基准分 + 周榜前 50%」为双重门槛按周滚动发放。仅跑官方模版或小幅修改的参赛者无法触发滚动发放，防止为薅算力盲目报名端到端赛道。

### 2.4 每周运营动作清单

| 时间  | 动作  | 耗时估算 |
|-----|-----|------|
| 每周一 | 周榜前 30% 自动触发发放 | 平台自动 |
| 每周一 | 端到端按周滚动名单核对发放 | 平台自动 |
| 每天  | 处理社媒申请 | 约 10–30 分钟 |
| 赛季末 | 决赛名单触发一次性奖励 | 平台自动 |
